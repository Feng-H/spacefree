使用监控钩子

钩子会在你每次敲命令时记录"哪个 brew 包被调用"（纯 shell 内建实现，<1ms 开销）。卸载随时可逆。安装时会顺带开启 zsh 历史时间戳（EXTENDED_HISTORY），让历史数据也能提供"最后使用时间"。

进阶：全局进程监控（可选）

Shell 钩子只能记录"终端里敲的命令"。如需监控 GUI/后台对 brew 程序的调用（如 IDE 调用 clang-format），可安装 eslogger LaunchDaemon（需要管理员）。下载 plist 后按文件内注释安装。SpaceFree 会自动解析其日志并计入使用统计。

欢迎使用 SpaceFree

首次使用请先全量扫描：读取 Homebrew 清单、使用历史、应用使用记录与缓存占用。
